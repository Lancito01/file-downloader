# 🚀 Quick Start - File Downloader

## To run this app, you need 3 things:

### 1. ✅ Node.js (you probably have this)
Check: `node --version`
If not: https://nodejs.org/

### 2. ✅ Rust compiler
Check: `cargo --version`
If not: https://rustup.rs/ (then restart computer)

### 3. ⚠️ Visual Studio Build Tools (IMPORTANT!)
Check: Search Start Menu for "x64 Native Tools Command Prompt"
If not found: https://visualstudio.microsoft.com/downloads/#build-tools-for-visual-studio-2022
- Select "Desktop development with C++"
- Restart computer after install

---

## 🎯 How to Launch:

### ✨ Easiest Way (Recommended):
```powershell
.\setup-and-run.ps1
```
This script checks everything and launches the app automatically!

### 🔧 Alternative:
```cmd
run.bat
```
